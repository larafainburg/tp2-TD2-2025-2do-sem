# TP2 - Plantas vs Zombies en C
Versión simplificada del juego *Plantas vs Zombies*, donde se trabajó principalmente con memoria dinámica y estructuras de datos. A partir de un prototipo base del juego, se refactorizó el sistema reemplazando arrays estáticos por listas enlazadas para manejar las plantas y los zombies de forma más flexible y eficiente.

Además, se implementaron funciones para el manejo de strings en C, junto con la lógica principal del juego, incluyendo la creación y eliminación de plantas, movimiento de zombies y actualización del estado del tablero.
Manejo de punteros, listas enlazadas, memoria dinámica y estructuras de datos en C.
